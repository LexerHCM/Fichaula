### Sistema de Gestión Escolar

Un sistema web diseñado para profesores y directores que facilita el seguimiento académico y disciplinario de los alumnos.

**Público objetivo:**
- Docentes
- Directivos / administradores escolares

**Función principal:**
- Registrar y administrar comentarios sobre los estudiantes
- Guardar observaciones de comportamiento, calificaciones o cualquier anotación relevante

**Funcionalidades clave:**
- Los docentes pueden añadir comentarios personalizados por alumno
- Los administradores pueden gestionar cuentas de profesores
- Los administradores también pueden editar datos de los estudiantes (DNI, fecha de nacimiento, etc.)

**Valor:**
- Centraliza la comunicación y el historial de alumnos
- Simplifica el control de datos personales y la gestión de roles
- Apoya la toma de decisiones con información organizada sobre cada estudiante
